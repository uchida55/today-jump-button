# 📅 今日のトピックジャンプボタン
### Today Jump Button

Webページ内の日付を自動判定し、**今日、または直近の過去のトピックへジャンプするボタン**です。

**Version: v0.5**

## ✨ 特徴

- 📅 今日の日付のトピックへジャンプ
- ⬅️ 今日がなければ **直近の過去の日付** へ移動
- ➡️ 過去の日付がなければ **最も近い未来の日付** へ移動
- 🔍 `10/1` と `10/10` を誤認しない正確な日付判定
- 📆 年またぎに対応
- 💬 今日のトピックがない場合は移動先をメッセージ表示
- ✨ 移動先を一時的にハイライト
- 🧩 JavaScriptを別ファイル化して管理
- 🧪 `index.html` ですぐに動作確認可能

## 🎯 移動ルール

移動先は次の優先順位で決定します。

**今日 → 直近の過去 → 過去がなければ最も近い未来**

### 例

| 今日 | ページ内の日付 | 移動先 |
|---|---|---|
| 10/1 | 10/1、10/2 | 10/1 |
| 10/1 | 9/25、10/2 | 9/25 |
| 10/1 | 9/30、10/5 | 9/30 |
| 10/1 | 10/2、10/10 | 10/2 |
| 10/10 | 10/2、10/5 | 10/5 |
| 1/2 | 12/31、1/5 | 12/31 |

未来の日付は、見出しだけ先に作成されていて内容が未作成の可能性があるため、  
**今日以前の直近のトピックを優先**します。
